# Names this project must not define, because a system header on one of our
# platforms already defines them. Checked by tools/check_ss_prefix.sh.
#
# The SS_ prefix is short, and two headers we include (transitively) own names
# in it. Regenerate the Windows half against the SDK you ship with:
#
#   grep -hoE '^\s*#\s*define\s+SS_[A-Z0-9_]+' <sdk>/winuser.h \
#     | awk '{print $NF}' | sort -u
#
# Blank lines and #-comments are ignored.
